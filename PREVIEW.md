## 🎬 Animations & Interactions

### On Page Load
1. Hero grid lines start pulsing (staggered)
2. Giant chevron starts breathing animation
3. Scan effect moves across hero background

### On Scroll
1. Navigation adds shadow after 100px
2. Product cards fade in when visible (Intersection Observer)
3. Value items fade in when visible
4. Stats fade in when visible

### On Hover
1. **Logo:** Chevron moves right
2. **Nav Links:** Yellow underline animates in
3. **Buttons:** Lift up 2px + yellow glow shadow
4. **Product Cards:** Lift up 4px + stronger shadow + yellow border
5. **Product Links:** Chevron moves right
6. **Footer Links:** Color changes to white

### On Focus (Keyboard Navigation)
- All interactive elements: Yellow outline (2px solid) with 2px offset
- Matches hover states for consistency

## 📱 Responsive Breakpoints

### Desktop (1280px+)
- Two-column hero (content left, visual right)
- Two-column product grid
- Three-column value props
- Two-column contact (info left, form right)
- Four-column footer

### Tablet (768px - 1279px)
- Single-column hero (visual smaller)
- Two-column product grid (stacks on smaller tablets)
- Two-column value props
- Single-column contact
- Two-column footer

### Mobile (<768px)
- Single-column everything
- Hamburger menu navigation
- Stacked buttons
- Larger tap targets (44x44px minimum)
- Simplified animations (reduced motion respected)

## ⚡ Performance Features

### Optimizations
- No external JavaScript libraries (vanilla JS only)
- Minimal CSS (design system variables)
- Font preconnect for faster loading
- Intersection Observer for lazy animations
- Hardware-accelerated CSS transforms
- `will-change` hints for animated elements

### Loading Strategy
1. Critical CSS inline (if needed for production)
2. Fonts load async (Google Fonts)
3. Images lazy load (future-proof code ready)
4. Scripts load at end of body

### Expected Metrics
- First Contentful Paint: <1s
- Time to Interactive: <2s
- Total Blocking Time: <100ms
- Cumulative Layout Shift: 0

## 🔍 Accessibility Features

### Keyboard Navigation
- Tab order: Logo → Nav Links → CTA → Form → Footer
- Focus visible: Yellow outline on all interactive elements
- Skip to content: (can add if needed)
- Escape key: Closes mobile menu

### Screen Readers
- Semantic HTML5: `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- ARIA labels: Navigation toggle, form fields
- Alt text: (no images yet, but code ready)
- Landmarks: Proper document structure

### Motion & Contrast
- `prefers-reduced-motion`: Disables animations
- Color contrast: 21:1 (White on Black) exceeds WCAG AAA
- Yellow on Black: 12.4:1 exceeds WCAG AA
- Large text: All compliant
