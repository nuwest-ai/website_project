# Psycho-Informational Risk (PIR) — Project README

## Overview
Psycho-Informational Risk (PIR) explores the intersection of:
- Epistemology (how humans construct reality)
- Media governance and influence
- Pornographic platform behavioural data
- Surveillance capitalism
- Security vulnerabilities arising from intimate behavioural data

This project develops a structured argument that PIR represents an **unrecognized category of human security risk** on par with (or exceeding):
- PII (Personally Identifiable Information)
- PHI (Protected Health Information)
- PCI (Payment Card Information)

---

## Objectives
1. Build a philosophical foundation (epistemology + media theory).
2. Define PIR formally as a new category of behavioural-data risk.
3. Analyse the business, data, and security vulnerabilities of Aylo (formerly MindGeek).
4. Develop a coherent framework for explaining and modelling PIR.
5. Produce an essay, whitepaper, or talk that synthesizes these threads.
