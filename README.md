# Nuwest.ai Website Project

**Status:** Phase 1 MVP - Ready to Start
**Last Updated:** November 7, 2025

---

## Project Goal

Create a modern, dynamic website for nuwest.ai that captures leads and projects a professional VC-backed security startup image with a distinctive black/yellow color scheme.

---

## 📋 Project Documents

- **[PROJECT_PLAN.md](PROJECT_PLAN.md)** - Complete two-phase development plan with task breakdown
- **[STYLE_GUIDE.md](STYLE_GUIDE.md)** - Comprehensive design system and brand guidelines

---

## 🚀 Two-Phase Approach

### Phase 1: MVP Lead Capture Site (2-4 hours)
**Goal:** Get a branded lead capture page live ASAP

**Deliverables:**
- Single-page responsive website
- Brand-compliant design (black/yellow theme)
- Working lead capture form
- Mobile-optimized layout

**Prerequisites:**
- Existing "coming soon webpage" content
- Headline and value proposition copy
- Logo or brand text
- Form backend service (Formspree recommended)

### Phase 2: Full Production Website (6-10 weeks)
**Goal:** Complete production-ready site with all features

**Deliverables:**
- Multi-page website (Home, Product/bsdetector, About, Services, Contact)
- Legal pages (Privacy Policy, Terms, Cookie Policy)
- Advanced lead capture system
- SEO, analytics, and security implementation
- Full testing and documentation

---

## 🎨 Design System

**Color Palette:**
- Primary: Black backgrounds (#000000)
- Accent: Yellow highlights (#FFD700)
- Supporting: Whites, grays for contrast

**Style:**
- Modern, clean, professional
- High contrast for readability
- Subtle animations and interactions
- VC-backed startup aesthetic

See [STYLE_GUIDE.md](STYLE_GUIDE.md) for complete design specifications.
